# 派单简报模板

子会话和外部 AI 看不到你们的聊天，简报必须自包含。复制下面的框架，把【】换成实际内容。

```
【任务】一句话：要做成什么，给谁用。

【背景】对方必须知道、但看不到的前情：用户原话、已经定下的决定、之前试过没成的办法。

【地方】
- 工作目录：【完整路径】
- 要读的文件或链接：【完整路径或链接】

【限制】
- 权限：只读 / 只许改【某目录】
- 不许做：【删除、对外发送、改生产……】
- 风格或口径：【如有】

【交付】交回什么，放在哪里：【文件路径或文档链接】

【完成标准】做到什么样算完：
1. 【可检查的标准】
2. 【可检查的标准】

【回报】做完先给结论，不超过 100 字，附交付物路径或链接；能写文件的，细节写进交付文件；只读任务，把完整结果附在回复最后。卡住超过两轮，回报卡在哪，不要硬编。
```

## 写简报时自查

- 路径是不是完整的，对方在别的目录也能找到？
- 用户的原话有没有原样带上，没被你转述走样？
- 权限是不是最小的？能只读就只读。
- 完成标准能不能被检查？「写得好」不算标准，「3 段、每段一个例子、事实都有出处」才算。
- 简报里有没有密码、key、客户真名？有就删掉。
