# 决策记录（定了的事、定了不做的事）

总管开口问人之前，先查这份记录。**定过的事不问第二遍；拒绝过的事，再碰到直接按记录回答。**

放在哪：项目根目录的 `.zongguan/decisions.md`（只管这个项目），或 `~/.zongguan/decisions.md`（全局）。两份都有时都读，项目的优先。

谁来写：用户拍板后，总管当场追加一条，写用户的原话，不改写。用户说「这条作废」，就把那条移到最后的「已作废」里，不删。

复制下面这段作为文件开头：

```markdown
# 决策记录

## 定了的事

- 2026-11-04 ｜对外发布的文案一律先存草稿，不直接发。｜原话：「以后都先存草稿，我看过再发。」
- 【日期】｜【一句话写清定了什么】｜原话：「【用户原话】」

## 定了不做的事

- 2026-11-04 ｜不接入付费的第三方监控服务。｜原话：「这个先不花钱。」
- 【日期】｜【不做什么】｜原话：「【用户原话】」｜以后再碰到怎么答：【一句话】

## 已作废

- 【日期作废】｜【原条目】｜作废原因：「【用户原话】」
```

## 写的时候注意

- 一条只写一件事。用户一句话里拍了两件事，就拆成两条。
- 写清楚适用范围。「这个项目的发布先存草稿」和「所有发布都先存草稿」是两回事。
- 不往里写密码、key、客户真名。这份文件可能被多个 AI 读到。
